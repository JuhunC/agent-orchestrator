---
name: ui-preview
description: Look at the agent-orchestrator admin UI in the browser pane with local data, to check a UI change at desktop and phone width.
---
1. `npm run build` (the UI goes to web/dist; about 0.3 s).
2. A data folder in the scratchpad: copy the repo's `profiles/` into `<scratch>/profiles` (rename `boards/product.yaml.example` → `product.yaml` and `groups/developers.yaml.example` → `developers.yaml` for a board and a group), then fill the database: `DATA_DIR=<scratch>/data node --disable-warning=ExperimentalWarning .claude/skills/ui-preview/seed.ts` (46 finished tasks with events and usage, running/queued tasks, PR outcomes, two schedules, webhooks, incidents, audit rows, board cards, a repository base branch). For secrets, import `seal` from `src/server/secrets.ts`, e.g. a registered GitHub account: `setSetting("agent_account:coder", JSON.stringify({ login, id, name, avatarUrl: "", scopes, token: seal("x"), savedAt }))`.
3. `.claude/launch.json`: configuration `orchestrator-preview`, `runtimeExecutable` `node`, `runtimeArgs` `["--disable-warning=ExperimentalWarning", "src/index.ts"]`, `port` 3123, `env` `{ PORT: "3123", DATA_DIR, PROFILES_DIR, AUTH_DISABLED: "true", WEB_DIST_DIR: "web/dist" }` (add any env the feature needs). The sign-in page needs a second one with `AUTH_DISABLED: "false"` and an `ADMIN_TOKEN` you make up, on another port.
4. `preview_start` it, then `resize_window` to 1440x900 (the pane's own size is small) and navigate to `http://localhost:3123/?v=<n>#/<page>`: bump `v` after each rebuild, or the pane keeps the old index.html and assets. The page scrolls inside Astryx's layout, so bring a panel into view with javascript_tool: `[...document.querySelectorAll('h2')].find(h => h.textContent === '<Title>').scrollIntoView()`. Screenshot at scale 0.7–0.8. Check light and dark (`resize_window` `colorScheme`), and `preset: "mobile"` for phone width (the side nav becomes a menu button, "Open navigation").
5. A dialog screenshot taken right after opening catches its fade-in (the page shows through): wait a second. `find` gives refs for Astryx buttons (they show as "generic").
6. `preview_stop`, and delete `.claude/launch.json` (it isn't part of the repo).

A flood of `ERR_CONNECTION_REFUSED` in the console comes from an earlier preview's event stream reconnecting: ignore it. 404s for `/api/profiles/file` are the editor probing files that don't exist yet.
